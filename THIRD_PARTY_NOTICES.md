# Third-party notices

## Vazirmatn font

The Vazirmatn font (`Vazirmatn.woff2`) is embedded into the injected runtime for Persian and
Arabic glyph rendering. Vazirmatn is published by Saber Rastikerdar and the
Vazirmatn Project Authors (https://github.com/rastikerdar/vazirmatn) under the
SIL Open Font License 1.1. The licence text is [Vazirmatn-OFL.txt](Vazirmatn-OFL.txt); it
is copied next to the font in every installer.

`Vazirmatn-UI-Regular.ttf` and `Vazirmatn-UI-Bold.ttf` are the
same font (version 33.003) as static Regular (400) and Bold (700) instances of
the variable font, made with fontTools so the companion's own windows can use
it. They are loaded for the companion's process only and are not installed in
Windows. The font has no Reserved Font Name.
